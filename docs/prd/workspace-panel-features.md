# 워크스페이스 작업 패널 신규 기능 PRD

> 승인 후 구현. Part 3-C 항목.

## 1. 포커스 타이머

- **설명:** 뽀모도로 25/5분 타이머 + 작업 메모
- **위치:** 워크스페이스 우측 패널 탭
- **수용 기준:** 타이머 시작/일시정지/리셋, 세션 카운트, 메모 localStorage 저장

## 2. 북마크/스니펫 패널

- **설명:** AI 답변 중 중요 구절 저장 및 태그 분류
- **API:** 기존 chatHistory + 신규 `Snippet` 모델 또는 userSettings JSON
- **수용 기준:** 텍스트 선택 → 저장, 태그 필터, 클립보드 복사

## 3. 빠른 번역

- **설명:** 선택한 텍스트를 내장 번역 API로 즉시 번역
- **구현:** 기존 `doc-translate` 퀵툴 API 재사용, 패널 UI만 경량화
- **수용 기준:** 선택 텍스트 500자 이내, 8개 UI 언어 대상

## 의존성

- 패널 탭 구조 (`ChatWorkspace` 우측 패널)
- i18n 키 추가 (`workspace.panel.*`)
